# Activity 05 — Add derived UI

Timebox: 8 minutes.

Add a greeting history:

1. Store each successful greeting in an array state value.
2. Render the messages as a list below the request counter.
3. Do not add failed requests to the history.

Done when two successful requests produce two list items, an error leaves the list unchanged, and existing loading/error behavior still works. Checkpoint 06 contains one possible solution.
