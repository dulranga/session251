# Activity 01 — Make the page yours

Timebox: 5 minutes.

1. Change the heading and helper text without removing the `h1`, `label`, or input `id`.
2. Choose a new button background color and a related hover color.
3. Use Tab to reach the input and button.

Done when the page still fits at a narrow mobile width, the label focuses the input when clicked, and keyboard focus is clearly visible. The button intentionally does nothing yet.
