# Activity 03 — Follow the request

Timebox: 8 minutes.

1. In browser developer tools, find the `POST /api/greetings` request and inspect its request and response JSON.
2. Temporarily change the API path to `/api/not-found`, observe the error, and then restore it.
3. Add a distinct message for a network failure.

Done when success, backend validation, and network failure each produce useful feedback; the button is disabled only while waiting and becomes usable afterward.
